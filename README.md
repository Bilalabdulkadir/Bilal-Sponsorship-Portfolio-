## 💻 Running the Double Portfolio App Locally

### Prerequisites
Make sure you have **Node.js** installed on your machine.

### Installation & Launch Steps

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Set up environment variables:**
   Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key (optional/server integrations).

3. **Run the developer environment:**
   ```bash
   npm run dev
   ```

4. **Open the browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the application interactively.
